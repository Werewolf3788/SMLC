Search Setup

What is already done on the site

  • Done Every page has a title, description, canonical link and share preview (Open Graph).
  • Done Questions & answers on the home page and every town page, tagged as FAQ so Google and AI tools can quote them.
  • Done Upcoming events are tagged as Events on the home and town pages, so they can show up in Google's event results.
  • Done sitemap.xml, robots.txt and llms.txt (the page list for AI tools).
  • Done IndexNow key file and an automatic ping to Bing whenever pages change on main.

The steps below are the parts only the site owner can do, because Google and Bing need proof that you own the domain.

1. Google Search Console

Scott, one time, ~10 min
  1. Go to search.google.com/search-console and sign in.
  2. Click Add property → choose Domain → type supportmylocalcommunity.com.
  3. Google shows a TXT record. Add it in the domain's DNS settings (where the domain was bought), then click Verify. It can take up to an hour.
  4. Left menu → Sitemaps → enter sitemap.xml → Submit.
  5. Left menu → Settings → Users and permissions → Add user → raykevin71888@gmail.com, permission Restricted (read only). This lets the Site Pulse ranking card read your search positions.

After a few days Search Console shows which searches bring people to SMLC and where each page ranks.

2. Bing Webmaster Tools

Scott, one time, ~3 min
  1. Go to bing.com/webmasters and sign in (a Google account works).
  2. Choose Import from Google Search Console. It copies the verified site and sitemap over, no extra DNS work. (Do step 1 first.)
  3. Bing also feeds ChatGPT search, Copilot and DuckDuckGo, so this covers most AI answer tools too.

3. IndexNow (automatic)

Nothing to do

When a page changes on main, the GitHub workflow .github/workflows/indexnow.yml tells Bing, Yandex, Seznam and Naver the same minute, instead of waiting for them to crawl.

Key file: /1281c43a4c58737ba44a202409aef432.txt. It must stay in the site root. If the site moves to another host, copy that file too.

To send every page right now: GitHub → Actions → Ping search engines (IndexNow) → Run workflow.

4. Ranking card on Site Pulse

Kevin, one time
  1. Get a free key (starts with opr_live_, 30,000 lookups a month) at openpagerank.keywordseverywhere.com and paste it into the Keys sheet row openpagerank_api_key (already added).
  2. Make a new Apps Script project, paste apps-script/SeoPulse.gs, and turn on Show appsscript.json in Project Settings; paste apps-script/appsscript.seo.json into it (adds the Keys library).
  3. Run setupSeoPulse once and allow access. It then runs by itself every morning.

The card shows the Authority score (0–10), Google clicks / views / average position, the top searches and top pages. Google numbers appear once step 1 is done and Kevin is added as a user.
