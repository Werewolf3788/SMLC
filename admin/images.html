How to get a token (2 minutes)
  1. Open github.com/settings/personal-access-tokens/new (Fine-grained token).
  2. Token name: SMLC images. Expiration: up to you (1 year is fine).
  3. Repository access: Only select repositories → Werewolf3788/SMLC.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Click Generate token, copy it, and paste it below.

The token is saved only in this browser on this device. It never goes into the website code. Anyone using this device's browser could use it, so only save it on your own computer or phone.
